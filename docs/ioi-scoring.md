# 대회 채점 제도와 서브태스크

ZOJ는 기존 AC/WA 대회와 서브태스크 점수제 대회를 구분한다. 서브태스크는 IOI 2024 공식 규칙의 고정 배점 채점 방식을 따른다.

- ICPC 공식 규정: https://icpc.global/regionals/rules
- IOI 공식 채점 규칙: https://www.ioi2024.org/contest-rules (Scoring)

## AC/WA 대회 — ICPC

기존 대회의 기본값이다. 정답 문제 수가 많은 팀이 우선하며, 같으면 기존 대회 벌점·동점 규칙을 적용한다. 부분 점수는 사용하지 않는다. 이 유형에는 서브태스크 채점 문제를 가져올 수 없다.

## IOI 점수제 대회

문제마다 100점 만점이며, 고정 배점의 서브태스크를 구성할 수 있다. 서브태스크를 구성하지 않은 일반 문제는 전체 테스트 통과 시 100점, 그 외에는 0점이다.

각 제출에서 서브태스크에 속한 모든 테스트가 정답이어야 해당 배점을 얻는다. 같은 테스트가 여러 서브태스크의 공통 조건으로 포함될 수 있다. 특정 서브태스크에 실패해도 다른 독립 서브태스크의 채점을 계속한다. 오답 하나로 나머지 전체 채점을 중단하면 안 된다.

IOI 공식 규칙의 계산 순서는 다음과 같다.

1. 각 제출의 테스트별 결과로 서브태스크별 점수를 계산한다. 고정 배점 문제에서 테스트 결과는 해당 배점을 얻거나 0점이다.
2. 동일한 서브태스크에 대해 모든 유효한 제출 중 최고 점수를 보존한다.
3. 서브태스크별 최고 점수를 합산해 문제 점수를 계산한다.
4. 문제 점수를 합산해 대회 총점을 계산한다.

예를 들어 30점 서브태스크와 70점 서브태스크가 있고, 첫 제출은 앞의 서브태스크만, 두 번째 제출은 뒤의 서브태스크만 통과하면 최종 문제 점수는 100점이다. 제출 한 건의 최고 총점인 70점으로 계산하지 않는다.

총점 내림차순으로 정렬하고 총점이 같으면 공동 순위다. IOI 모드에 ICPC 오답 벌점이나 제출 시각을 임의의 동점 기준으로 추가하지 않는다. 화면에 보이는 시각은 운영 참고 정보다.

## 문제 설정과 에디터

대회 설정에서 채점 방식을 IOI 점수제로 선택한 뒤 문제의 테스트 세트에 서브태스크를 구성한다. 이름, 배점, 포함할 테스트를 지정하며 배점 합계는 100점이어야 한다. 각 서브태스크는 하나 이상의 유효한 테스트를 포함해야 한다.

에디터에서는 기본 정보에서 부분 점수를 켜고 테스트의 그룹 관리에서 그룹 전체 통과 정책을 설정한다. 각 테스트를 그룹에 배정하고 그룹 배점을 지정한다. 기존 에디터 자료의 그룹 배점은 테스트별 점수의 합계다. 그룹 의존성은 선행 그룹의 테스트까지 해당 서브태스크의 통과 조건에 포함하도록 변환한다. 내보낼 테스트 세트와 배점의 합계를 검증한 뒤 커밋본으로 ZOJ 패키지를 생성한다.

이번 지원 범위는 표준 입출력 문제의 고정 서브태스크 배점이다. 최적화 결과에 비례하는 Checker 백분율 점수, 인터랙티브·출력 전용 문제, grader 결합 기능까지 지원한다는 뜻은 아니다. 지원하지 않는 설정은 호환성 검사에서 설명과 함께 거절하며 배점 의미를 자동 변경하지 않는다.

## 채점 결과와 재채점

제출의 원래 판정과 획득 점수는 별도로 저장한다. 예를 들어 제출 결과가 시간 초과여도 이미 통과한 서브태스크의 30점은 표시할 수 있다. 컴파일 오류는 0점이다. 채점기 오류, 결과 누락, 불완전한 실행은 정상 0점으로 확정하지 않는다.

채점은 서버가 저장한 테스트 세트·서브태스크 구성의 스냅샷을 기준으로 한다. 채점기가 보낸 총점을 그대로 신뢰하지 않고 테스트별 결과로 서버에서 계산한다. 구버전 채점기에는 점수제 작업을 배정하지 않는다. 배점 구성이 다른 버전의 점수를 임의로 합산하지 않는다.

재채점은 해당 제출의 예전 점수를 대체한다. 점수가 내려갈 수도 있으므로 모든 유효 제출을 다시 집계한다. 같은 판정이라도 서브태스크 점수가 달라졌다면 결과 변경으로 처리하며 되돌리기에도 점수와 구성 정보가 포함된다.

## 공개, 프리즈, 리졸버

공개 스코어보드는 서버에서 공개 가능한 제출만 대상으로 서브태스크 최고점을 계산한다. 프리즈 이후 제출의 점수·서브태스크 결과·최고 제출 식별자가 공개 응답을 통해 노출되면 안 된다.

리졸버에서 팀의 문제를 공개할 때 그 문제의 모든 관련 제출을 대상으로 서브태스크 최고점을 반영한다. 첫 정답 제출을 찾았다는 이유로 탐색을 멈추지 않는다. 되돌리기는 이전 공개 점수와 순위를 복원한다.
